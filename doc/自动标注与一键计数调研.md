## 可选路线

| 路线 | 能做到什么 | 对当前业务的判断 |
| --- | --- | --- |
| X-AnyLabeling | 桌面预标注，集成 GeCo2、SAM 3、YOLO 等，修正和导出 | 推荐作为标注工作台；更换工具本身不提升现有 GeCo2 的识别能力 |
| CVAT | 批量自动预标注、标签映射、人工复核，可接自有模型 | 适合多人及批量数据；单机起步可优先较轻的桌面工具 |
| CountGD++ | 文本提示计数、自动伪示例，支持不手工框示例的推理设置 | 值得作为免示例通用对照；系统仍需明确计数对象，不能推断任意图片的业务计数单位 |
| SAM 3 | 文本或视觉提示的实例分割，输出可用于预标注 | 可研究粘连棉头边界；密集实例是否分开需要验证，不能直接把所有掩膜数量当可靠根数 |
| 专用轻量检测/点定位 | 用核验业务标注训练，部署时无需人工提示 | 推荐长期生产路线；检测与点定位按真实漏检/重复和延迟选择，不预先断言哪种最好 |
| 传统颗粒分割 | 无示例、低计算量，定位背景简单的分离米粒 | 已有单图验证；复杂背景、粘连、重叠应另测 |

## 建议下一步（尚未运行）

1. 以三类业务各收集一小批真实图建立试验集，逐实例核验；当前网络样本只是启动对照，不足以验收。
2. 用 GeCo2 / CountGD++ / SAM 3 预标注，修正后形成训练标签。仅需计数时优先中心点，不要求每根都描轮廓。
3. 冻结独立拍摄批次的测试集，比较文本免示例计数、专用检测/点定位、米粒分割三条路线。
4. 统计每图完全正确率、漏检、多检和耗时，排除同图变体跨训练测试造成的泄漏。
5. 客户流程可统一为上传→识别→数量及标点；研究阶段允许品类预设。若要求系统自行判断类别，应另测类别路由错误，不能把它隐藏。
6. 为避免占用其他项目资源，后续推理服务采用显式启动、单任务运行、空闲卸载或独立子进程推理后退出；当前没有部署这些生命周期机制。
